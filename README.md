# SUMARO

## AI/ML-Based Intelligent Dead Reckoning System for Seamless Navigation

Smart India Hackathon 2026 — PS SIH26168

### Objective

SUMARO is a smartphone-based intelligent navigation system primarily focused on 2-wheelers. It aims to maintain continuous position estimation during GNSS outages using smartphone sensors, dead reckoning, sensor fusion and AI/ML-based corrections.

### Current Status

Early Development

### Core Workstreams

- Vehicle Dead Reckoning
- EKF / Sensor Fusion
- Machine Learning Corrections
- GNSS-Denied Navigation
- Sensor-Adaptive Navigation
- Mobile Application
